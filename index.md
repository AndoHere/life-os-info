# Life OS

Life OS is a personal notes, tasks and planning app for one person. It runs on that person's own laptop and Android phone and keeps everything in plain files in a private Git repository that the user owns.

It is not a public service. There is no account to create, no server run by the developer, and no data collected by the developer.

## What the app does with Google

If you sign in with Google inside Life OS, the app asks for one permission: `https://www.googleapis.com/auth/drive.file`. This lets Life OS see and manage only the files it created itself in your Google Drive, such as attachments and backups. It cannot see any other file in your Drive.

Read the [privacy policy](privacy).
